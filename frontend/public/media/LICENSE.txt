Format: VP8 in WebM, 480 x 270 pixels, 6 fps, 8 seconds, silent.
All film fixture routes intentionally share this explicitly disclosed test clip.

Regeneration is optional, never required to run MUNK. It requires Node.js, the sharp
Node module (SHARP_MODULE can point at an installed copy), and FFmpeg with MJPEG
decoding, libvpx/VP8 encoding and WebM muxing (FFMPEG_PATH can select the binary).
