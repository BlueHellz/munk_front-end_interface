# Foundation tests

Run `npm run test:backend` from the root. Tests exercise real ES256 signatures through Privy's SDK verifier, hashed sessions/CSRF/logout replay prevention and HTTP House isolation, plus configuration, migrations/rollback, SQL constraints, storage reopen, actual FFmpeg output and synthetic manual review/expired-lease recovery. Default result: 8 passed, 3 native cases skipped without TEST_DATABASE_URL. `npm run test:native --workspace backend` starts a disposable native PostgreSQL 18.4 process: latest result 8 passed, 0 skipped, plus a process restart persistence probe. Provider user lookup is a fixture in automated tests; no test key/config bypass exists in server.ts. Live Privy signup/recovery, actual human review and full browser acceptance are not established by those fixtures. See PRIVY-DEVELOPMENT.md for the manual walkthrough and POSTGRESQL-SETUP.md for external-server testing.
